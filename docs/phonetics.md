# BHARTI MODERN CODE (BMC) — PHONETICS & ALPHABET

## 1. VOWELS (स्वर) — Fixed Phonemes
* `a` : /ə/ (अ)
* `aa` : /ɑː/ (आ)
* `i` : /ɪ/ (इ)
* `ii` : /iː/ (ई)
* `u` : /ʊ/ (उ)
* `uu` : /uː/ (ऊ)
* `e` : /eː/ (ए)
* `o` : /oː/ (ओ)

---

## 2. CONSONANTS (व्यंजन) — Standard Phonemes
* **Velars (क-वर्ग):** `k` (क), `kh` (ख), `g` (ग), `gh` (घ)
* **Palatals (च-वर्ग):** `c` / `ch` (च), `j` (ज), `jh` (झ)
* **Retroflex (ट-वर्ग):** `tq` (ट), `dq` (ड), `dqh` (ढ)
* **Dentals (त-वर्ग):** `t` (त), `th` (थ), `d` (द), `dh` (ध)
* **Labials (प-वर्ग):** `p` (प), `ph` (फ), `b` (ब), `bh` (भ), `m` (म)
* **Approximants & Liquids:** `y` (य), `r` (र), `l` (ल), `v` (व)
* **Fricatives:** `s` (स), `sh` (श), `h` (ह)

---

## 3. PHONETIC INTEGRITY RULES
1. **1 Letter = 1 Sound:** Strict 1:1 mapping with standard English QWERTY keypresses.
2. **Zero Silent Letters:** Every letter written in a word MUST be pronounced.
3. **No Contextual Variation:** `c` or `g` will never change sound based on following vowels.
